Your OBS

reel connects to the OBS you run, over the WebSocket server that OBS 28 and later have built in: OBS tells reel the moment it saves a replay, and reel reads where it writes it. In OBS, open Tools, WebSocket Server Settings and tick Enable WebSocket server; Show Connect Info there has the port and the password.

What reel found

The replay buffer

reel saves clips from OBS's replay buffer: the last minutes, kept in memory and written to a file when you save. It needs the buffer on in OBS's profile, and running. What reel changes in OBS, it asks OBS for over the WebSocket; it never writes OBS's files.

Quality

What the clips are recorded at. Smooth suits most games and links; Light, at 30 frames a second, asks about half as much of the PC, and fast motion looks less fluid; Sharp keeps small text readable; Native records the screen as it is.

Encoder

reel tries each encoder OBS could use here with a short test encode, the graphics card's first: they leave the game more room than the CPU. Each one that passes is then tried in OBS itself, which starts again for it, so only an encoder OBS records with can be picked. All of them write H.264, so reel keeps the clips as they are.

New versions
